# Phase 2 Portfolio Project 6 — US Accidents

This repository contains the US Accidents portfolio project, with analysis, preprocessing, and modeling work.

## Repository structure
- `code/` — Jupyter notebooks for exploratory data analysis, preprocessing, and model development.
- `data/` — Dataset metadata and data placement instructions.
- `docs/` — Project documentation and workflow notes.
- `queries/` — Example SQL queries for analyzing the accident dataset.

## Notes
The raw dataset is not included in this repository. Download the US Accidents dataset from the original provider and place it in `data/` before running the notebooks.
