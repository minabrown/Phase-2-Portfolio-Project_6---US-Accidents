# Data

This folder contains metadata and pointers for the dataset used in the US Accidents portfolio project.

## Dataset
- Source: US Accidents dataset for traffic accident analysis in the United States.
- Expected file(s): `US_Accidents.csv`, `US_Accidents_June20.csv`, or similar.

## Notes
- Raw data files are not included in this repository due to file size and licensing.
- Download the dataset from the official provider or dataset source before analysis.
- Place the downloaded CSV files in this folder before running the notebooks.

## Recommended structure
- `data/US_Accidents.csv`
- `data/processed/` (optional folder for cleaned outputs)
